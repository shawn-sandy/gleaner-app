Requirements

One host is enough to start. Connectors are optional, and each one adds a place to keep your clips.

Claude

Chrome side panel, Cowork and Claude Code

Required

  • A paid Claude plan with the new Chrome side panel, or Claude Code

    The new panel's three-dot menu shows Switch back to classic.

Optional

  • Google Drive connector

    Saves clips to Drive and syncs your preferences.

  • Notion connector

    Saves each clip to a Browser Research database.

  • A session that publishes artifacts, such as Claude Code

    Saves clips as private pages on claude.ai.

Claude requirements in the README

ChatGPT

Connected Chrome tabs and the Work browser

Required

  • A workspace with GitHub marketplace import enabled

    Menus and import permissions depend on your workspace's admin policy.

Optional

  • Browser access

    Connected Chrome tabs or the Work browser let Gleaner read the page you're on. Without them, paste a URL or the text.

  • Google Drive

    Saves clips to Drive and syncs your preferences.

  • Notion

    Saves each clip to a Browser Research database.

ChatGPT setup and compatibility

Nothing else is needed for the default. Each clip comes back in the conversation: a Markdown file in ChatGPT, an HTML file in Claude.
