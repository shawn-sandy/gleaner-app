Requirements

Pick one host to install Gleaner. Everything after that is optional.

Required

Pick one host

  • Claude

    A paid plan with the new Chrome side panel, or Claude Code.

    The new panel's three-dot menu shows Switch back to classic.

  • ChatGPT

    A workspace with GitHub marketplace import enabled.

    Connect browser access too, or paste a URL or the text. Your admin policy decides the menus.

Optional

Add a place to keep clips

  • Google Drive

    Saves clips to a Browser Research folder and syncs your preferences.

  • Notion

    Saves each clip to a Browser Research database you can filter and sort.

  • Artifacts

    Saves a private page on claude.ai, from a session that publishes artifacts, such as Claude Code.

Default

Nothing to connect

Every clip comes back in the conversation: a Markdown file in ChatGPT, an HTML file in Claude.

Open a page and say save this page.

Pick a default destination later with /gleaner:preferences setup.
