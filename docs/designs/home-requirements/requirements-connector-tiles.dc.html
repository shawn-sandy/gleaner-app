Requirements

What each piece unlocks. You need one host; the rest you connect when you want it.

Pick one host

  • Required

    Claude

    A paid plan with the new Chrome side panel, or Claude Code.

    Unlocks Gleaner in the Chrome side panel, Cowork and Claude Code.

  • Required

    ChatGPT workspace

    GitHub marketplace import enabled. Your admin policy decides the menus.

    Unlocks Gleaner in your workspace's chats.

Connect when you want it

  • ChatGPT

    Browser access

    Connected Chrome tabs or the Work browser.

    Unlocks Clipping the tab you're on. Without it, paste a URL or the text.

  • Optional

    Google Drive

    The Google Drive connector.

    Unlocks Saving to Drive and syncing your preferences.

  • Optional

    Notion

    The Notion connector.

    Unlocks A Browser Research database of your clips.

  • Optional

    Artifacts

    A session that publishes artifacts, such as Claude Code.

    Unlocks Clips as private pages on claude.ai.

Nothing to connect for the default. Each clip comes back in the conversation: a Markdown file in ChatGPT, an HTML file in Claude. Open a page and say save this page.
