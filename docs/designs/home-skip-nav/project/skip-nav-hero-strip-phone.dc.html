A web clipper for Claude and ChatGPT

Gather the best of what you read.

Ask in plain words to save a page, a passage, a YouTube moment or the answer you just got. Gleaner writes a short summary, tags it, files it by topic and hands it to you as a Markdown file in ChatGPT or an HTML file in Claude, or saves it where you choose. Later, ask what you saved there and it finds it.

Install Gleaner See an example

In Claude Code

/plugin marketplace add shawn-sandy/gleaner
/plugin install gleaner@shawn-sandy

Gives you each clip as a Markdown file in ChatGPT or an HTML file in Claude, or saves it to Google Drive, Notion, a Cowork project, your Claude Code project or a private claude.ai artifact.

Open source, MIT licensed. Needs a paid Claude plan or a ChatGPT workspace.
